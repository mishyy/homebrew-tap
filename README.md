# mishyy tap

## How do I install these formulae?

`brew install mishyy/tap/<formula>`

Or `brew tap mishyy/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "mishyy/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
